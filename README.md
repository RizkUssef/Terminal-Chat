# Terminal-Chat

Terminal-Chat is a real-time messaging application built with Laravel and Laravel Reverb. It focuses on providing a fast, seamless, and interactive chat experience with real-time updates and modern aesthetics.

## 🌟 Core Features

### ⚡ Real-Time WebSockets
Powered by **Laravel Reverb** and **Laravel Echo**, Terminal-Chat ensures instant message delivery. You can send and receive messages without needing to refresh the page, creating a fluid conversation experience.

### 🔔 Background Audio Notifications
Never miss a message. The application includes a built-in audio notification system that alerts you to new incoming messages even when your browser tab is out of focus or inactive.

### 🔒 Secure Authentication
User accounts and access control are handled securely via **Laravel Fortify**, ensuring that your conversations remain private and that only authenticated users can participate.

### 💬 Private Conversations
Easily connect with other users and manage private chat sessions. The interface allows you to view your ongoing chats and switch between them effortlessly.

### 🎨 Modern UI & UX
The frontend is built with **Blade Components** and styled using the latest **Tailwind CSS v4**. It features a clean, responsive, and dynamic interface designed for optimal user engagement across devices.

## 🛠️ Technology Stack

**Backend Engine:**
- PHP 8.3+
- Laravel 13.x
- Laravel Reverb (WebSockets Server)
- Laravel Fortify (Authentication Backend)

**Frontend Architecture:**
- Vite (Asset Bundling)
- Tailwind CSS v4 (Utility-first Styling)
- Laravel Echo & Pusher-js (WebSocket Client)
- Blade Templates (Server-rendered UI Components)
